## ✨ Overview

EyadCode Calculator is a lightweight, modern calculator featuring a sleek glassmorphism interface, neon accents, and intuitive interactions.

Built with pure HTML, CSS, and JavaScript, it combines elegant design with practical functionality and a custom arithmetic parser — without "eval()".

---
## 🚀 Features

- 🎨 Premium dark UI with glassmorphism effects.
- 📱 Fully responsive across screen sizes.
- 🧮 Essential arithmetic operations.
- ⌨️ Keyboard support for faster calculations.
- 🛡️ Custom expression parser without "eval()".
- 🧱 Organized CSS using BEM methodology.
- ⚡ Lightweight with zero external dependencies.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/eyad-codes/YOUR_REPOSITORY.git
```

### 2. Navigate to the Project Directory

```bash
cd YOUR_REPOSITORY
```

### 3. Run the Calculator

Open `index.html` in your browser, or use **Live Server** in VS Code.

> **Note:** Replace `YOUR_REPOSITORY` with your actual repository name.

## ⌨️ Keyboard Shortcuts

| Key | Action |
|:---:|---|
| `0–9` | Enter numbers |
| `+ - * / %` | Mathematical operators |
| `Enter` or `=` | Calculate the result |
| `Backspace` | Delete the last character |
| `Escape` or `Delete` | Clear the calculation |

## 🎨 Customization

Personalize the calculator by adjusting the CSS custom properties in `style.css`, including colors, spacing, and border radii.
